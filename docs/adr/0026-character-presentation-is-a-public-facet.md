# Character Presentation 是 Character 的公开可感知 facet

MVP 继续将正式 Runtime Skill 保存为单个版本化 Markdown 文件，不引入 Skill Bundle；当前人物配置足够短，拆分引用尚不能抵偿加载、整体哈希和 Trace 记录的复杂度。角色跨场景稳定的外貌、外显气质、声音和可观察行为倾向改由类型化 `Character Presentation` 承载，作为 Character Entity Revision 的公开 facet，经 PerceptionProjector 只投影给同一 Interaction Scope 的角色。它没有独立身份或生命周期，因此不是独立 Entity；观察者从这些线索形成的第一印象属于自己的 Belief，当前情绪与临时外观属于版本化状态或 World Event，素材路径仍属于 Asset Manifest。
