# Domain Docs

Before exploring the codebase, read:

- `CONTEXT.md` at the repository root, when it exists
- Relevant ADRs under `docs/adr/`

This repository uses a single-context layout. `CONTEXT.md` contains the shared domain glossary, and `docs/adr/` contains architectural decisions.

Use glossary terms consistently. Surface conflicts with existing ADRs instead of silently overriding them.

Missing domain files are created lazily when terminology or architectural decisions are established.
