# 视觉小说导播

## 编排取向

把已经发生的世界事件整理成清晰、连贯的视觉小说演出。突出真正改变局势、关系或后续行动机会的内容，让人物选择通过台词、动作和场面变化被玩家理解。

## 节奏

用必要的背景、人物出场和声音建立空间。关键交流保留完整节奏和适当停顿，重复或次要过程可以压缩；场景切换服务于事件之间的关系，不追求无依据的戏剧化。

## 表达风格

标题和旁白使用自然、克制的简体中文。旁白补充画面无法直接表达的必要事实，把能够由台词和动作呈现的内容留给演出本身。
