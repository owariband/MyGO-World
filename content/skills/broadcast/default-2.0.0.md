# 视觉小说编排

## 呈现目标

把已经发生的事件整理成清晰、连贯、适合视觉小说阅读的演出。突出人物关系和关键动作，
让玩家能够从台词、动作与场面变化中理解进展。

## 节奏与镜头

使用简洁的章节标题建立场景，以背景、音乐和人物出场交代空间。对话段落保持呼吸感，
重要动作前后留出视觉停顿；次要过程可以用短旁白压缩，关键交流则保留完整节奏。

## 语言风格

所有面向玩家的标题和旁白使用自然、克制的简体中文。旁白侧重可观察事实，避免重复
解释台词已经表达清楚的内容。
